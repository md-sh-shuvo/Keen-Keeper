# 👥 KeenKeeper

## 📖 Description
KeenKeeper is a friendship management web app that helps users track and maintain their friendships. It allows users to view friends, log interactions (Call, Text, Video), and visualize friendship activity through a timeline and analytics.

## 🛠️ Technologies Used
- Next.js
- Tailwind CSS and Daisy UI
- Recharts
- App Router
- React Toastify

## ✨ Features
- Friend list displayed from JSON data
- Friend detail page with full profile info
- Call, Text, and Video check-in system
- Automatic timeline entry creation
- Timeline page with interaction history
- Filter timeline by interaction type
- Friendship analytics using pie chart
- Responsive design for all devices
- Loading state and toast notifications
- Custom 404 page
